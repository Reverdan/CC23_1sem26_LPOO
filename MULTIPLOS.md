# Projeto Multiplos — Documento de Referência

Este arquivo descreve o escopo do projeto Multiplos e sua aplicação pedagógica em Java.

O projeto demonstra conceitos fundamentais de orientação a objetos, como validação de entrada, separação de responsabilidades entre classes de controle e cálculo, e organização de pacotes. Ele é utilizado como exercício introdutório para reforçar estruturas de projeto e lógica matemática em Java.
